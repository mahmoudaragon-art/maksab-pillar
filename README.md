# Maksab Pillar — stc bank walkway LED

- `/` — player (the screen). Press **Full screen**. It checks for new versions every minute and reloads itself.
- `/#control` — operator control panel (winner name, amount, 60 s sequence, blackout).
- `/#face1` … `/#face4` — one face only.
- `/preview-3d.html` — 360° preview of the 4.5 m pillar.

Output map: 4 faces × 540 × 2430 px = 2160 × 2430.
Control changes are signed with a private control key (kept off this repo); the screen ignores anything unsigned.
